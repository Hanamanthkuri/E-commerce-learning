About the Project
The E-Learning Web Application is a front-end web project that provides a centralized platform for course exploration and student interaction. It is designed to be responsive, visually appealing, and easy to use — covering all major features of a real-world Learning Management System (LMS).

 Features

🔐 User Registration & Login – Secure client-side authentication
🏠 Dashboard (Home Page) – Central navigation hub
📖 Course Listing – Browse available courses
📝 Course Enrollment – Enroll with a modal form
👤 Student Profile – Create and view personal profiles
📩 Contact Form – Submit queries with input validation
💾 LocalStorage – Client-side data persistence (no backend needed)
